#  Password Generator

A simple and responsive Password Generator built using HTML, CSS, and JavaScript.

##  Features

- Generate random passwords
- Choose password length
- Include uppercase letters
- Include lowercase letters
- Include numbers
- Include symbols
- Copy password to clipboard
- Password strength indicator
- Responsive design
- Input validation

##  Technologies Used

- HTML5
- CSS3
- JavaScript

1. Download or clone this repository.

2. Open the project folder.

3. Open `index.html` in your browser.

That's it!

##  How It Works

The application has four character sets:

- Uppercase letters
- Lowercase letters
- Numbers
- Symbols

The user chooses the password length and character types.

JavaScript combines the selected character sets and randomly selects characters until the requested password length is reached.

## 📸 Features

### Password Length

The user can select a password length from 4 to 50 characters.

### Character Types

Users can choose:

- A-Z
- a-z
- 0-9
- Symbols

### Password Strength

The application analyzes the generated password and displays:

- Weak
- Medium
- Strong
- Very Strong

### Copy Password

The Copy button copies the generated password to the clipboard.
